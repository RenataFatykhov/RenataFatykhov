# Book Club · ручные тест-кейсы

Стенд: https://book-club.qa.guru. Тестовые аккаунты: `manual_<timestamp>` и `manual_other_<timestamp>`, пароль `QaDiploma2026!`. Для каждого независимого сценария использовать новые данные. API: `/api/v1`. Для негативных API-проверок подойдёт Postman. Удалять только созданные для проверки отзывы.

Все кейсы подготовлены к выполнению. Статус каждого — **Не выполнен**; это не отчёт об успешном прогоне. Перед выполнением зафиксировать дату, сборку/URL, браузер или устройство. После прогона записать фактический результат и приложить доказательства; при расхождении завести дефект.
